# HSIC-SPT
# Improving Hyperspectral Image Classification through Self-Supervised Pretraining and Transfer Learning on Spectral Vision Transformers

This repository contains the official implementation of the paper:

**“Improving Hyperspectral Image Classification through Self-Supervised Pretraining and Transfer Learning on Spectral Vision Transformers.”**

🚧 **Repository Status:** Under Development

The source code, pretrained models, configuration files, and instructions for reproducing the experiments will be added to this repository progressively.

## Contents

The repository will include:

- Source code for the proposed method
- Self-supervised pretraining implementation
- Spectral Vision Transformer architecture
- Transfer learning pipeline
- Training and evaluation scripts
- Dataset preparation instructions
- Pretrained model weights
- Experimental configurations and results

## Availability

The repository is currently under development. The complete implementation and accompanying resources will be released upon completion.

More details will be provided in this README as the repository is updated.
